CloudFile is a free, open-source file management and collaboration platform for enterprise integration. It builds on Seafile CE and connects managed files to existing business systems, professional desktop applications and optional storage, preview and AI services.

## Users And Value

| Need | Product value |
| --- | --- |
| Engineering and R&D files | Versions, access control and local professional applications |
| PLM, OA and ERP integration | Reusable file APIs with business rules in the consuming system |
| Existing Seafile deployments | Enterprise extensions with version-specific upgrade checks |
| Historical and scattered files | Optional read-only reference access and controlled import |

## Product Direction

Invest in reliable files and versions, permissions and scoped sharing, enterprise APIs, professional local editing and maintainable delivery. Reuse mature open-source services for storage, previews, search, document parsing and AI where they meet the required boundaries.

CloudFile owns file semantics. Business systems own projects, approvals, menus and business metadata mappings. The file core can run without a desktop Agent, external reference browser or customer adapter. Optional components have their own lifecycle and compatibility requirements.

## Open Product And Services

General-purpose product capabilities belong in public components where rights permit. CF-Agent follows a complete open-source product direction; general editing, recovery, UI and update capabilities are part of that direction. Customer-specific business adapters may be maintained separately under their applicable licenses and contracts. Public build independence is a delivery goal, not a claim that every platform package already meets it.

Software use follows component licenses; consulting, implementation, migration, customization and support are paid services. See [principles](principles.md), [capabilities](capabilities.md) and [roadmap](roadmap.md).
