# 产品方案

[English](../en/product.md) | [简体中文](../zh-CN/product.md)

[产品首页](../../README.zh-CN.md) · [文档导航](README.md)

CloudFile 是免费开源、面向企业业务集成的文件管理与协作平台。基于 Seafile CE，让受管理文件连接现有业务系统、专业桌面软件以及可选的存储、预览和 AI 服务。

## 用户与价值

| 需求 | 产品价值 |
| --- | --- |
| 工程研发文件 | 版本、访问控制与本地专业软件 |
| 业务系统接入 | 复用文件 API，业务规则留在消费方 |
| 既有 Seafile 部署 | 企业扩展与按版本核对的升级路径 |
| 历史与分散资料 | 可选只读参考入口与受控导入 |

## 产品方向

长期投入可靠文件与版本、权限和限定分享、企业 API、专业本地编辑以及可维护交付。存储、预览、检索、文档解析和 AI 优先集成满足边界要求的成熟开源服务。

CloudFile 负责通用文件语义，业务系统负责项目、审批、菜单及业务字段映射。文件核心可独立于桌面 Agent、外部参考浏览器和客户适配运行；可选组件各有生命周期与兼容条件。

## 开源产品与服务

具备公开权利的通用产品能力进入公开组件。CF-Agent 按完整开源产品方向发展，通用编辑、恢复、界面及更新能力属于这一方向。客户专属业务适配可按适用许可和合同独立维护。公开源码独立构建是交付目标，不表示当前所有平台发行包均已做到。

软件使用遵循组件许可证；咨询、实施、迁移、定制和支持属于收费服务。详见 [产品原则](principles.md)、[能力说明](capabilities.md)与[路线图](roadmap.md)。
