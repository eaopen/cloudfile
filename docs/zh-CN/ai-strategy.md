# AI 长期方向

[English](../en/ai-strategy.md) | [简体中文](../zh-CN/ai-strategy.md)

[产品首页](../../README.zh-CN.md) · [文档导航](README.md)

CloudFile 的长期方向是让企业文件成为 AI 与业务系统可信赖的资源。模型能力不能自行确定访问者权限、有效版本、业务上下文与获准操作。文件、权限、来源追溯和接入契约仍是长期投入重点。

## 规划能力

| 能力 | 必要结果 |
| --- | --- |
| 解析与提取 | 文本、字段及摘要绑定来源版本 |
| 权限感知检索 | 候选及引用遵循当前授权 |
| 可追溯回答 | 标明文件、版本和片段，过期结果失效 |
| 业务关联 | 接入业务引用，保留外部业务模型 |
| 受控操作 | 受限凭据、服务端校验、必要复核与可恢复结果 |
| 多源访问 | 来源授权、明确根范围与可重建索引 |

## 集成方法

适合时复用 Seafile AI，通过适配评估独立解析、搜索与 RAG/Agent 服务。Docling、RAGFlow、Paperless-ngx 是调研候选，不是已支持组合。选型前比较真实格式、部署成本、许可、来源引用、撤权及故障恢复；借鉴同类开源产品公开设计并遵循其许可。

先做只读解析与检索，再做经复核的元数据建议，最后进入受限执行。AI 输出和索引是派生数据，不替代原文件、权威权限或正式业务结果的人工审核。敏感文件内容遵循企业的模型部署与数据访问策略。

以任务完成、引用可用、权限正确及人工工作减少衡量价值。CAD/3D 先从属性、预览和可提取文本入手；几何与 BOM 理解需要可靠专业解析器和真实场景。
