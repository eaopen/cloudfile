[开源与商业化基本原则](principles.md)

CloudFile 软件按开源许可证提供，通过专业服务帮助组织完成适配、部署和持续维护。

| 服务 | 范围 |
| --- | --- |
| 咨询 | 文件组织、权限、存储与集成方案 |
| 实施 | 安装部署、配置与运维交接 |
| 迁移 | 历史资料导入、Seafile 升级方案 |
| 定制开发 | 业务 API、身份对接与专属工作流 |
| 技术支持 | 按约定提供故障排查、升级与维护 |

通用能力在公开产品中持续发展；客户专属业务逻辑和部署信息可保留在独立客户项目中，并遵守适用许可与合同。服务范围、验收标准、支持承诺和费用按项目约定；社区使用不附带服务等级承诺。

可通过 [Issues](https://github.com/eaopen/cloudfile/issues) 提交不含保密信息的需求概述，约定私密沟通渠道后再提供业务敏感信息。
