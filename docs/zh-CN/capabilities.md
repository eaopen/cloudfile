# 能力与选用说明

[English](../en/capabilities.md) | [简体中文](../zh-CN/capabilities.md)

[产品首页](../../README.zh-CN.md) · [文档导航](README.md)

本文按 2026-10-13 的产品方向说明能力领域，不是某一发行版本的支持矩阵。部署前核对所选版本的配置与兼容说明。

| 领域 | 用户价值 | 选用边界 |
| --- | --- | --- |
| 文件与版本 | 库、上传下载、历史与共享 | 继承 CE，核对版本支持入口 |
| 企业权限 | 库准入、目录规则与限定协作 | ACL 与分享按入口和版本确认，限定分享不等于整库访问 |
| 身份与 API | 企业登录与业务集成 | 身份声明与适配需配置，草案接口不代表稳定 API |
| 搜索与属性 | 文件发现、描述和标签 | 可选索引服务，名称标签检索不代表所有格式全文支持 |
| 预览 | 原生预览与可选增强格式 | 增强预览单独配置，格式支持随查看器版本 |
| 本地应用 | 专业软件打开文件 | 平台与包支持不同，提交成功才形成服务端版本 |
| 受控本地编辑 | 签出、提交、恢复与任务状态 | 开发候选需桌面到服务端验收，路线图不等于启用 |
| 存储 | 本地按库布局与兼容 S3 类 | RustFS 分支后端验证不等于生产迁移验收 |
| 外部参考资料 | 可选只读浏览，减少一次性迁移需求 | 来源授权与根隔离单独验证 |
| AI 文件能力 | 可选 AI 文件工作流 | 已有配置入口，权限感知知识访问与自动化仍属发展方向 |

技术状态与证据见[组件能力矩阵](https://github.com/eaopen/cloudfile-docker/blob/dev/docs/feature-matrix.md)；开发快照不能覆盖发行包的支持范围。
