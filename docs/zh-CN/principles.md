# CloudFile 开源与商业化基本原则

[English](../en/principles.md) | [简体中文](../zh-CN/principles.md)

[产品首页](../../README.zh-CN.md) · [文档导航](README.md)

**开源优先、Apache 2.0 优选、尊重上游许可、为客户定制保留空间、以专业服务支持持续发展，并积极回馈开源生态。**

## 1. 开源优先

CloudFile 以开源方式发展通用产品。具有通用价值的能力与改进进入公开产品，让使用者能够按照适用许可证自主部署、使用和定制，并通过客户实际需求持续完善共享的产品能力。

## 2. Apache 2.0 优选

CloudFile 新增的独立自主开发代码优选 Apache 2.0，支持复用、企业集成和下游定制。已有合理许可证，包括 MIT，可以继续保留。具体许可与版权声明以各组件为准。

## 3. 尊重上游许可

CloudFile 保留 Seafile、Filestash 等上游项目的许可证，包括受 AGPLv3 覆盖的代码。Apache 优选原则不意味着对上游派生代码重新许可。只有实际客户定制需求需要时，才结合代码来源和技术耦合评估架构拆分；改变仓库、插件或部署边界本身不改变许可义务。

## 4. 为客户定制保留空间

CloudFile 通过企业 API 和集成能力，支持客户对接自身身份体系、业务流程和应用。客户专属实现可以独立维护，其权属、交付与源码提供范围遵循适用许可证及合同约定；具有通用价值且具备相应权利的改进，优先回到公开产品。

## 5. 软件免费，服务收费

CloudFile 围绕专业服务开展商业化，包括咨询、定制开发、实施部署、历史数据迁移、从 Seafile 升级以及持续技术支持。使用者可以在遵守许可证的前提下使用开源软件，无需购买服务。付费服务另行约定范围、验收标准、费用和支持承诺。

## 6. 持续发展，回馈上游

服务收入用于支持产品维护、质量提升与长期发展。CloudFile 力所能及地向上游贡献通用修复、文档和改进，尊重上游维护者的正当利益，不主动破坏上游利益，不使用未经授权的专有代码。与开源生态合作是长期产品原则。

## 相关说明

本原则说明 CloudFile 的产品方向与服务模式。软件权利以组件许可证为准，服务承诺以约定合同为准。
