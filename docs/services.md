# Professional Services / 专业服务

[Product home / 产品首页](../README.md) · [中文首页](../README.zh-CN.md)

CloudFile software is available under its open-source licenses. Professional services support organizations that need assistance adapting, deploying or maintaining it.

CloudFile 软件按开源许可证提供，通过专业服务帮助组织完成适配、部署和持续维护。

| Service / 服务 | Scope / 范围 |
| --- | --- |
| Consulting / 咨询 | File organization, permissions, storage and integration design / 文件组织、权限、存储与集成方案 |
| Implementation / 实施 | Installation, configuration and operational handover / 安装部署、配置与运维交接 |
| Migration / 迁移 | Historical data imports and Seafile upgrade planning / 历史资料导入、Seafile 升级方案 |
| Custom development / 定制开发 | Business APIs, identity integration and dedicated workflows / 业务 API、身份对接与专属工作流 |
| Support / 技术支持 | Troubleshooting, upgrades and maintenance by agreement / 按约定提供故障排查、升级与维护 |

Reusable capabilities are developed in the public product. Customer-specific business logic and deployment information can remain in separate customer projects, subject to applicable licenses and contracts. Scope, acceptance criteria, support commitments and fees are agreed for each engagement; community use does not imply a service-level agreement.

通用能力在公开产品中持续发展；客户专属业务逻辑和部署信息可保留在独立客户项目中，并遵守适用许可与合同。服务范围、验收标准、支持承诺和费用按项目约定；社区使用不附带服务等级承诺。

Start a non-confidential enquiry through [Issues](https://github.com/eaopen/cloudfile/issues). Share sensitive business information only after agreeing a private communication channel.

可通过 [Issues](https://github.com/eaopen/cloudfile/issues) 提交不含保密信息的需求概述，约定私密沟通渠道后再提供业务敏感信息。
